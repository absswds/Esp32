## 2. 实验组 A：TEC1-12703 vs TEC1-12706 满压对比

**目的：** 在同一散热配置下，对比 12703（3A/36W）与 12706（6A/72W）两种 TEC 芯片的制冷与加热性能，为大体积被动散热箱体选择更合理型号。

**测试条件：** 12V 满压直供；同一组 DS18B20 + 同一组散热器；比例控温旧韧体（`ab6141f`，见 §1 韧体版本注意）。功耗 36W/72W 为 12V × 额定电流的**估算值**，未实测电流。
**起点统一（用户 2026-09-10 确认）：** 制冷前先把箱内加温/平衡到统一起点 ~29-30°C（A1 29.5 / A3 29.1，两次差 0.4°C），再测降温幅度，保证 12703 vs 12706 可比；加热段（24.9→31.9/31.6）把温度升回，完成循环。预热过程本身不在 CSV 记录内。08-01 起只跑制冷一遍，不再统一控制起点。

### 2.1 制冷对比（A1 vs A3）

|------|----------------|----------------|
| 数据行数 | 616 | 609 |
| 时长 | 17:43:10 → 17:53:25 (10:15) | 16:07:30 → 16:17:38 (10:08) |

| 巢穴 min/max | min 24.9 @17:51:45 / max 29.8 @17:43:29 | min 24.8 @16:15:14 / max 29.5 @16:07:58 |

**结论（A1 vs A3）：**
- 两种 TEC 制冷能力接近、**12703 略優**（Δ 4.6 vs 4.2，速率 0.449 vs 0.414 °C/min，快约 8%；按时间戳时长 615 s / 608 s 计。旧版文档写 0.448，是把 616 行当成 616 秒）。
- 12703 估算功耗约 36W vs 12706 约 72W（12V × 额定电流，未实测），散热压力小约一半，性价比明显胜出。
- 在 29°C 起点无外箱环境降温幅度仅 ~4.6°C，**接近散热器与环境温差极限**——这是后来引入铜片 + 密封箱 + 风扇降速的动因。

### 2.2 加热对比（A2 vs A4）

| 指标 | A2 12703 加热 | A4 12706 加热 |
|------|----------------|----------------|
| 数据行数 | 296 | 310 |
| 时长 | 17:53:47 → 17:58:30 (4:43) | 16:18:23 → 16:23:31 (5:08) |
| 起始巢穴 | 24.9 | 24.9 |
| 终止巢穴 | 31.9 | 31.6 |
| 巢穴 Δ | **+7.0 °C**（速率 1.484 °C/min） | **+6.7 °C**（速率 1.305 °C/min） |
| 出風口 Δ | 25.5→31.5 (+6.0) | 25.3→31.9 (+6.6) |
| 活動區 Δ | 25.0~31.0 (+6.0) | 24.9~31.6 (+6.7) |
| 风档 | {0, 39, 100} | {0, 100} |
| 异常 | 起始连续 13 行时戳重复 `17:53:48`（浏览器 polling 时间戳重复；故 296 行实际只有 283 s） | **狀態列開頭出现"製冷"（2 行）**——疑似误触发，紧接加熱前 |
| 状态分布 | 維持 → 加熱 → 維持 | 維持 → **短暫"製冷"（開頭）** → 加熱 → 維持 |

**结论（A2 vs A4）：**
- 12703 加热速率（1.484 °C/min）**胜 12706（1.305 °C/min），快约 14%**（按时间戳时长 283 s / 308 s 计）；电源适配器匹配后再无优势理由选 12706。
- 加热约为制冷的 3.2–3.3× 速率——Peltier 焦耳热叠加泵热效应，效率天然更高。
- 加热速率 1.3–1.5 °C/min 高于脂尾袋鼩**自身体温**的自然甦醒速率 0.7~1.0 °C/min（Lopatko 1999）。注意：论文实验流程写的是「人为快速复温、环境温度快速回升至 24 °C」，**并未规定箱体加热速率上限**，所以这不是"超标"；若想模拟自然复温才需要 PI + 速率限制（可选改进，LIMITATIONS #2）。
- A2/A4 在默认加热目标 28°C（旧韧体）下一直加热到 31.9 / 31.6°C 才回維持，结合少量 39% 风扇行，推测当时为手动/测试端点驱动而非严格按目标控温（CSV 不记录目标值，无法确认）。
- A4 開頭（維持 → 製冷 2 行 → 加熱）出现"製冷"异常状态：手动 bang-bang 切出阈值时控制标志被旧 PWM 误置（或 `/test` 手动操作干扰），需后续日志深究。

### 2.3 A 组总评

- **TEC1-12703 是首选**：制冷持平（甚至略好），加热更快，估算功耗仅一半。
- 加热速率高于动物自然甦醒体温速率；论文未规定箱体复温速率上限，若要模拟自然复温可再加 PI 控制 + `maxRate` 节流（可选，详见 [CONFIG_GUIDE] §3.3）。

- 8.5V 降压后制冷幅度下降约 21%（−3.62 vs −4.6），加热幅度下降更多，约 29%（+4.96 vs +7.0）。按速率算：制冷 −24%（0.342 vs 0.449），加热 −36%（0.948 vs 1.484）。

- 但降压导致最大制冷差变浅（出風口 min 26.13 vs 25.4），在 24°C 室温下连 15°C 目标都远不可达，**降压仅适合温度维持阶段而不适合快速制冷**。

B 系列读数为 2 位小数（25.77），A 系列为 1 位小数（25.7）——同套源码下不应出现精度差异，**怀疑 B 系列是在 DS18B20 12-bit 改造之后（commit enabling 12-bit resolution）或前端 `toFixed(2)` 切换之后所录**。切换时点可从 CSV 定位：7/23 11:48:48（`短测试5分钟` 最后仍为 1 位小数）到 11:59:59（`短测试7分钟` 首行已是 2 位小数）之间。

## 4. 实验组 C：密封箱实测（08-01）

**目的：** 在 3D 打印密封箱 + 0.3mm 铜片夹层 + 热端 7cm 5500RPM 风扇的条件下，**验证能否将出風口降至 15°C**，并探索冷端风扇速度对制冷效果的影响。（注意：论文的 15°C 指**实验舱内环境温度**——24°C 降至 15°C、维持 4 h 后人为快速复温回 24°C；出風口是箱内最冷点，出風口到 15°C 只是必要条件，不等于箱内环境达标。）
（本次起只跑制冷一遍：无统一起点控制、无加热段。起点巢穴 26.34°C，与 A/B 组 ~29-30 起点不可直接比 Δ。）

**关键改动（A→C 之间）：**
1. 铜片夹在 TEC 热面与散热器之间，两面涂散热膏。效果（用户 2026-09-26 手测回忆，无 CSV 记录）：无铜片时 TEC 冷面约 16–17°C、加铜片后约 5–6°C；箱内出風口无铜片约只到 24–26°C（P1 最低 24.07），加铜片后风扇 100% 约 18.6°C（本组数据）。（旧版文档的"ΔT 从 1.4°C 提升到 18.5°C"来源不可考，已删除。）
2. 冷端 X 形内鳍片铝型材，气流穿过鳍片缝隙换热。
3. 箱体 20×24×16 cm，3D 打印 PLA 壁厚 2~3mm；XPS 20mm 保温约 08-22 才装好（用户 2026-09-26 回忆），此次实验**未贴保温板**。
4. 引入冷端风扇 PWM 控制试验（50% / 52% 均为网页滑条**手动**设定）。

**数据规模：** 2793 行数据，47:06 时长，是 A/B 系列的 4 倍以上。

### 4.2 风扇速度的关键发现

| 风扇档 | 出風口最低 | 结论 |
|--------|----------:|------|
| **100% 全速** | 18.63 | 稳态平台；全速气流热负载大，冷端被吹热 |
| **50%（手动）** | 17.33 | 只跑了 4:44（11:54:20–11:59:04），到 17.33 时仍以约 0.28°C/min 下降，**未到稳态** |
| **52%（手动）** | **14.87** | 跑了约 23 分钟且起点已预冷；出風口首次 ≤15°C（巢穴仍 22°C） |
| **0% 关停中段** | 反弹到 20.93（其后 100% 段继续升到 21.81） | 关停=失去主动制冷 |

**物理解释：** 冷端风量本身是热负载——全速时每秒把大量室温空气强行送到冷端面前，TEC 被迫把泵热能力花在「冷却新进空气」上，冷端温度被拉高。降速后空气在鳍片内停留更久、换热更充分，冷端能维持更低温度。**风扇不是越快越好**——这是与传统直觉相反的关键发现。

> ⚠️ **结论边界：** 数据只能支持「**降速（约 50%）优于全速 100%**」。50% 与 52% 的差距（17.33 vs 14.87）主要来自运行时长与起点不同，**不能说明 52% 优于 50%**，也没有做过档位扫描，"52% 最优"证据不足。

### 4.3 巢穴 vs 出風口温度差

- 出風口 14.87°C vs 巢穴 22.19°C = **Δ ≈ 7.3°C**。
- 原因：3D 打印 PLA 箱壁 2~3mm 严重漏热，冷气从出风口循环到对角最远端（巢穴）已被环境热量加热。
- 活動區最低 19.75°C，处于两者之间，符合空间梯度分布。

**结论：** 仅靠出風口达 15°C **不等于动物实际所在位置的巢穴已达**。后续必须做：
1. 箱内壁贴 XPS 20mm 保温板（约 08-22 装好） → 隔绝漏热，预期巢穴降至 17~18°C。**实测（P3 0826，见 §10）未达预期**：有 XPS、风扇 100%，连续制冷 38:35 期间巢穴 26.10→26.50 未降、出風口真实最低 16.76°C（风扇 100% 而非 52% 是混杂因素，保温效果仍需同风速对照才能量化）。
2. 巢穴局部冷区方案：用 XPS 剩料把巢穴隔成约 1/6 体积的小空间直接导冷风 → 小空间降温容易 6 倍。
3. 若仍不足：两级 TEC 串联 / 压缩机制冷 / 冰水循环（暂不需）。

### 4.4 14.9°C 达成时间线

- 首次 ≤15.0°C：**12:25:27**
- 首次 ≤14.95°C：**12:25:39**

## 6. 关键科学结论

1. **TEC1-12703 胜出 12706**：制冷略優 + 加热更快 + 估算功耗减半（A1↔A3、A2↔A4）。
2. **铜片夹层是散热关键技术**：散热器底面被铜片摊平后整面参与散热；用户手测 TEC 冷面由约 16–17°C 降到 5–6°C，出風口由 24–26°C 降到约 18.6°C（风扇 100%）（C 组前提；冷面温度为回忆值，无 CSV）。
3. **冷端风扇非全速更佳**：手动降速后出風口最低 14.87°C，全速 100% 仅 18.6°C（C 组核心反直觉发现）。只能证明"降速优于全速"，52% 是否最优未验证（见 §4.2）。
4. **密封箱出風口到 15°C 但箱内未达标**：出風口 14.87°C，但巢穴仍 22°C；论文的 15°C 是舱内环境温度，**不能说已达论文目标**。瓶颈是箱壁漏热而非 TEC 能力。
5. **降压 8.5V 可作复温节流档（可选）**：速率 0.948 °C/min 落在动物自然甦醒体温速率 0.7~1.0 °C/min 内，若将来要模拟自然复温可作基底档（B2 结论）。
6. **加热速率高于动物自然甦醒速率，但不算超标**：12V 下 1.3~1.5 °C/min。论文 0.7~1.0 °C/min 是动物**自身体温**的甦醒速率（Lopatko 1999），论文流程写的是人为快速复温，未规定箱体加热上限；PI + maxRate 属可选改进（步骤见 CLAUDE.md 本地笔记，未随库发布）。
7. **制冷速率天然慢**：~0.34–0.45 °C/min（A1 0.449 / B1 0.342），无需 maxRate。

## 8. 数据局限与建议

### 8.1 数据局限

1. **无环境温度记录**：P1–P3 的 CSV 仅含箱内三温度，**无室温/湿度**，无法精确算出散热器 ΔT 与露点（BME688 已于 2026-09-19 接入代码，之后导出的 CSV 会带箱内温湿压与露点列，待实体装机）。
2. **无源数据校准信息**：每次实验前的 `nestOff/roomOff/ventOff` 偏移未记录在 CSV 中。
3. **时戳精度仅秒级**：浏览器 `toLocaleString()`；高频切换（如 bang-bang 在 0.01 hysteresis 下）可能漏帧。
4. **B 组缺少对照（同条件 12V）**：B1/B2 是单独做的，没有在同一粘贴时间内配套 A 系列复测，基准漂移可能存在。
5. **C 组无重复**：仅一次实测，无第二次验证 14.87°C 可重现性。
6. **TEC 功率/电流未监控**：36W/72W 只是 12V × 额定电流的估算，缺少电参数。
7. **A4 异常"製冷"状态未根因分析**：A 组为比例控温旧韧体（§1），可能与 `/test` 手动操作或 control 旧标志残留有关，需配合 Serial 串口日志（已丢失）。
8. **CSV 不记录控制模式与目标值**：无法从数据判断当时是自动还是手动（网页製冷/加热按钮），只能靠风扇档位与探头状态推断（例如 0831 巢穴缺失仍连续制冷，只可能是手动，见 §10）。

### 8.2 后续实验建议

1. **重复 C 组密封箱实验 2~3 次**：验证 14.87°C 可重现性，并同时记录箱内温湿度（BME688 代码已接入，装机后 CSV 自带，对应 LIMITATIONS #4）。
2. **对照 XPS 保温板效果**：C 组未贴保温板；P3 0826 已贴但风扇 100%，需在同风速（手动 ~50%）下再做一次，才能量化保温板对巢穴温度的影响。
3. **冷端风扇扫描档位试验**：30 / 40 / 50 / 52 / 60 / 70 / 80 / 100 % 8 档，每档稳态 15 分钟，绘制"冷端风扇 % vs 出風口最低温"曲线，找到真正全局最小点（不一定是 52%）。
4. **进阶加热节流实验（可选）**：若要模拟自然复温，B2 8.5V 速率 0.948 °C/min 值得继续；用降压稳压源或 PWM 占空比限幅做 0.5/0.7/1.0 °C/min 三档对照（论文流程本身为人为快速复温，此项非必须）。
5. **加入环境温湿度与 TEC 电流监测**：电源线串 INA219 / ACS712 实时记录电流/功率。
6. **断电恢复实验**：人为拔电源后重插，验证 `loadState()` 是否正确恢复所有阈值与 `systemOn`。**按代码预期会失败**：`systemOn` 会恢复为 true，但 `setup()` 把 `TEC_EN` 拉低后只有 `startAll()` 会拉高，重启后 TEC 不通电（LIMITATIONS #31）；演示时重启后须先「停止」再「开启」。
7. **校准偏移后置叠加对照**：测三次同点温度，比较 nestOff 偏移前后差异，量化 DS18B20 出厂相对偏差。
