## 2. 实验组 A：TEC1-12703 vs TEC1-12706 满压对比

**目的：** 在同一散热配置下，对比 12703（3A/36W）与 12706（6A/72W）两种 TEC 芯片的制冷与加热性能，为大体积被动散热箱体选择更合理型号。

**测试条件：** 12V 满压直供；同一组 DS18B20 + 同一组散热器。
**起点统一（用户 2026-09-10 确认）：** 制冷前先把箱内加温/平衡到统一起点 ~29-30°C（A1 29.5 / A3 29.1，两次差 0.4°C），再测降温幅度，保证 12703 vs 12706 可比；加热段（24.9→31.9/31.6）把温度升回，完成循环。预热过程本身不在 CSV 记录内。08-01 起只跑制冷一遍，不再统一控制起点。

### 2.1 制冷对比（A1 vs A3）

| 指标 | A1 12703 制冷 | A3 12706 制冷 |
|------|----------------|----------------|
| 数据行数 | 616 | 609 |
| 时长 | 17:43:10 → 17:53:25 (10:15) | 16:07:30 → 16:17:38 (10:08) |
| 起始巢穴 | 29.5 °C | 29.1 °C |
| 终止巢穴 | 24.9 °C | 24.9 °C（实验无維持收尾） |
| 巢穴 Δ | **−4.6 °C** | **−4.7 °C**（速率 0.464 °C/min） |
| 巢穴 min/max | min 24.9 @17:51:45 / max 29.8 @17:43:29 | min 24.8 @16:15:14 / max 29.5 @16:07:58 |
| 出風口 min/max | 25.4→29.8 | 25.0→29.8 |
| 活動區 Δ | 25.0~29.4 (Δ≈4.4) | 24.8~29.6 (Δ≈4.8) |
| 风档 | {0, **39**, 100}（有 39% 启动过渡） | {0, 100}（无过渡） |
| 状态分布 | 維持 → 製冷 → 維持 | 維持 → 製冷（始终未回維持，实验提前结束） |

**结论（A1 vs A3）：**
- 两种 TEC 制冷能力几乎相当（Δ 4.6 vs 4.7，速率 0.448 vs 0.464 °C/min）。**12703 几乎与 12706 持平**。
- 12703 实际功耗仅 36W vs 12706 的 ~72W，散热压力小 50%，性价比明显胜出。
- 在 29°C 起点无外箱环境降温幅度仅 ~4.6°C，**接近散热器与环境温差极限**——这是后来引入铜片 + 密封箱 + 风扇降速的动因。

### 2.2 加热对比（A2 vs A4）

| 指标 | A2 12703 加热 | A4 12706 加热 |
|------|----------------|----------------|
| 数据行数 | 296 | 310 |
| 时长 | 17:53:47 → 17:58:30 (4:43) | 16:18:23 → 16:23:31 (5:08) |

| 出風口 Δ | 25.5→31.5 (+6.0) | 25.3→31.9 (+6.6) |
| 活動區 Δ | 25.0~31.0 (+6.0) | 24.9~31.6 (+6.7) |
| 风档 | {0, 39, 100} | {0, 100} |
| 异常 | 起始连续 3 行时戳重复 `17:53:48`（浏览器 polling 时间戳重复） | **狀態列出现"製冷"**——疑似误触发，未在制冷实验中 |
| 状态分布 | 維持 → 加熱 → 維持 | 維持 → 加熱 → **短暫"製冷"** → 維持 |

**结论（A2 vs A4）：**
- 12703 加热速率（1.484 °C/min）**略胜 12706（1.309 °C/min）**；电源适配器匹配后再无优势理由选 12706。
- 加热是制冷的 3× 速率——Peltier 焦耳热叠加泵热效应，效率天然更高。
- 加热时速率均**超过论文甦醒上限 0.7~1.0°C/min**（LIMITATIONS #2），是切 PI 控制的主要驱动场景。
- A4 末尾出现"製冷"异常状态：手动 bang-bang 切出阈值时控制标志被旧 PWM 误置（或 `/test` 手动操作干扰），需后续日志深究。

### 2.3 A 组总评

- **TEC1-12703 是首选**：制冷持平（甚至略好），加热更快，功耗仅一半。
- 加热速率天然超论文上限，必须靠 PI 控制 + `maxRate` 节流（详见 [CONFIG_GUIDE] §6.6 切 PI 控制说明）。

## 3. 实验组 B：TEC1-12703 降压试验（8.5V）

**目的：** 验证将 TEC 工作电压降到 8.5V 后能否：①降低电流/功耗/发热；②维持可用温控能力；③热端散热要求减弱。
**起点统一与 A 组同流程：** 制冷起点 29.39（与 A 组 ~29-30 同一起点控制），加热段把温度升回（25.75→30.71）。

### 3.3 B 组对比 A 组（12703 同型号，电压对比）

| 维度 | A1 12V 制冷 | B1 8.5V 制冷 | A2 12V 加热 | B2 8.5V 加热 |
|------|------------|--------------|------------|--------------|
| 巢穴 Δ | −4.6 °C | −3.62 °C | +7.0 °C | +4.96 °C |
| 出風口 min | 25.4 | 26.13 | 25.5 | 26.13 |
| 加速率 | ≈0.448/min | ≈0.345/min | ≈1.484/min | ≈0.948/min |

**结论（B 组）：**
- 8.5V 降幅后制冷能力下降更明显（−3.62 vs −4.6，**约 −21%**）；加热下降稍小（+4.96 vs +7.0，约 −29%）。
- 降压后加热速率 0.948 °C/min 更接近论文 0.7~1.0 °C/min 上限——**这是 8.5V 模式的一个意外优势**，可作为后续 PI 替代方案实验的一个"天然节流"档位。
- 但降压导致最大制冷差变浅（出風口 min 26.13 vs 25.4），在 24°C 室温下连 15°C 目标都远不可达，**降压仅适合温度维持阶段而不适合快速制冷**。

### 3.4 8.5V 系列数据精度差异

B 系列读数为 2 位小数（25.77），A 系列为 1 位小数（25.7）——同套源码下不应出现精度差异，**怀疑 B 系列是在 DS18B20 12-bit 改造之后（commit enabling 12-bit resolution）或前端 `toFixed(2)` 切换之后所录**；具体时序不在 CSV 中体现，但说明 **精度可配置且不同实验有切换记录**。

## 4. 实验组 C：密封箱实测（08-01）

**目的：** 在 3D 打印密封箱 + 0.3mm 铜片夹层 + 热端 7cm 5500RPM 风扇的条件下，**验证能否将出風口降至 15°C**（论文蟄眠诱导温度），并探索冷端风扇速度对制冷效果的影响。
（本次起只跑制冷一遍：无统一起点控制、无加热段。起点巢穴 26.34°C，与 A/B 组 ~29-30 起点不可直接比 Δ。）

**关键改动（A→C 之间）：**
1. 铜片夹在 TEC 热面与散热器之间，两面涂散热膏 → ΔT（TEC 热端到环境）从 1.4°C 提升到 18.5°C。
2. 冷端 X 形内鳍片铝型材，气流穿过鳍片缝隙换热。
3. 箱体 20×24×16 cm，3D 打印 PLA 壁厚 2~3mm + 后续 XPS 10mm 保温（此次实验**未贴保温板**）。
4. 引入冷端风扇 PWM 控制试验。

**数据规模：** 2793 行数据，47:06 时长，是 A/B 系列的 4 倍以上。

### 4.1 关键温度里程碑

| 时刻 | 风扇档 | 出風口 °C | 巢穴 °C | 活動區 |
|------|--------|---------|---------|--------|
| 11:42:00 起始 | 100% | 25.04 | 26.34 | 25.85 |
| 11:54:20 首次降速 | 50% | 18.67 | 23.34 | — |
| 12:00:38 中段停机 | 78%→0%→100% | 19.51→20.93 | 23.79→24.14 | — |
| 12:06:05 二次降速 | 52% | 18.68 | 23.56 | — |
| 12:25:27 | 52% | **15.00** | 22.31 | — |
| **12:28:03 min** | 52% | **14.87** | 22.19 | 19.75 |
| 12:29:06 结束 | 52% | 14.94 | 22.19 | 19.89 |

### 4.2 风扇速度的关键发现

| 风扇档 | 出風口最低 | 结论 |
|--------|----------:|------|
| **100% 全速** | 18.67 | 全速气流热负载大，冷端被吹热 |
| **50% 中速** | 17.30 | 降速立即见效率提升 |
| **52% 微调** | **14.87** | **达论文 15°C 目标 ✅** |
| **0% 关停中段** | 反弹到 20.93 | 关停=失去主动制冷 |

**物理解释：** 冷端风量本身是热负载——全速时每秒把大量室温空气强行送到冷端面前，TEC 被迫把泵热能力花在「冷却新进空气」上，冷端温度被拉高。降速后（30~52%），空气在鳍片内停留更久、换热更充分，冷端能维持更低温度。**风扇不是越快越好**——这是与传统直觉相反的关键发现。

### 4.3 巢穴 vs 出風口温度差

- 出風口 14.87°C vs 巢穴 22.19°C = **Δ ≈ 7.3°C**。
- 原因：3D 打印 PLA 箱壁 2~3mm 严重漏热，冷气从出风口循环到对角最远端（巢穴）已被环境热量加热。
- 活動區最低 19.75°C，处于两者之间，符合空间梯度分布。

**结论：** 仅靠出風口达 15°C **不等于动物实际所在位置的巢穴已达**。后续必须做：
1. 箱内壁贴 XPS 10mm 保温板（进行中） → 隔绝漏热，预期巢穴降至 17~18°C。
2. 巢穴局部冷区方案：用 XPS 剩料把巢穴隔成约 1/6 体积的小空间直接导冷风 → 小空间降温容易 6 倍。
3. 若仍不足：两级 TEC 串联 / 压缩机制冷 / 冰水循环（暂不需）。

### 4.4 14.9°C 达成时间线

- 首次 ≤15.0°C：**12:25:27**
- 首次 ≤14.95°C：**12:25:39**
- 12:25~12:29 期间 出風口稳定在 14.88~14.95 → 已达**热平衡**
- 起始到首次 ≤15°C 实际耗时：11:42 → 12:25 = **43 分钟**

### 4.5 数据异常

1. **中段停机回弹**（12:00:38~12:01:36）：出现 `78% → 0% → 100%` 短暂序列，说明用户中途关停或切换模式后再恢复；出風口从 19.5 反弹到 20.93 后再开始下行。
2. **时间戳使用中文"上午/下午"**：12:00 是"下午"而非上午，可能导致简单脚本解析混乱；建议解析时正则替换 `上午/下午` 为 `AM/PM` 后用 `Date` 解析，或直接用 `toLocaleString('zh-TW', {hour12:false})` 处理新数据。
3. **末行重复时戳 12:29:05**：连续两行同毫秒下同秒戳，浏览器 polling 抢帧。
4. **巢穴温度与出風口温度差大**：是后续工程难题（见 4.3）。

**关键横向发现：**

## 6. 关键科学结论

1. **TEC1-12703 胜出 12706**：制冷持平 + 加热更快 + 功耗半降（A1↔A3、A2↔A4）。
2. **铜片夹层是散热关键技术**：散热器底面被铜片摊平后整面参与散热，ΔT 从 1.4 → 18.5°C（C 组前提）。
3. **冷端风扇非全速更佳**：52% 反达 14.87°C 出風口最低，全速 100% 仅 18.6°C（C 组核心反直觉发现）。
4. **密封箱已気が达标但巢穴未达**：出風口 14.87°C < 论文 15°C ✅，但巢穴仍 22°C，瓶颈是箱壁漏热而非 TEC 能力。
5. **降压 8.5V 是加热天然节流档**：速率 0.948 °C/min 接近论文甦醒上限 0.7~1.0 °C/min，可作为 PI 节流替代实验的基底档（B2 结论）。
6. **加热速率普遍超论文上限**：12V 下 1.3~1.5 °C/min，**必须用 PI + maxRate 切回**（本地开发笔记留有 PI 重启步骤，未随库发布）。
7. **制冷速率天然慢，无超速风险**：~0.448 °C/min 远低于甦醒速率上限，无需 maxRate（A1/B1 综合）。

## 8. 数据局限与建议

### 8.1 数据局限

1. **无环境温度记录**：所有 CSV 仅含箱内三温度，**无室温/湿度**。无法精确算出散热器 ΔT 与露点。
2. **无源数据校准信息**：每次实验前的 `nestOff/roomOff/ventOff` 偏移未记录在 CSV 中。
3. **时戳精度仅秒级**：浏览器 `toLocaleString()`；高频切换（如 bang-bang 在 0.01 hysteresis 下）可能漏帧。
4. **B 组缺少对照（同条件 12V）**：B1/B2 是单独做的，没有在同一粘贴时间内配套 A 系列复测，基准漂移可能存在。
5. **C 组无重复**：仅一次实测，无第二次验证 14.87°C 可重现性。
6. **TEC 功率/电流未监控**：仅风量、温度间接推断功耗，缺少电参数。
7. **A4 异常"製冷"状态未根因分析**：可能与 `/test` 手动操作或 control 旧标志残留有关，需配合 Serial 串口日志（已丢失）。

### 8.2 后续实验建议

1. **重复 C 组密封箱实验 2~3 次**：验证 14.87°C 可重现性，并加入环境温度/湿度（DHT22 / BME280，对应 LIMITATIONS #4）。
2. **对照 XPS 保温板效果**：C 组未贴保温板；贴保温板后再做一次，量化保温板对巢穴温度的提升。
3. **冷端风扇扫描档位试验**：30 / 40 / 50 / 52 / 60 / 70 / 80 / 100 % 8 档，每档稳态 15 分钟，绘制"冷端风扇 % vs 出風口最低温"曲线，找到真正全局最小点（不一定是 52%）。
4. **进阶加热节流实验**：B2 8.5V 速率 0.948 °C/min 是值得继续的；用降压稳压源或 PWM 占空比限幅做 0.5/0.7/1.0 °C/min 三档对照，确认符合论文甦醒上限的最佳档。
5. **加入环境温湿度与 TEC 电流监测**：电源线串 INA219 / ACS712 实时记录电流/功率。
6. **断电恢复实验**：人为拔电源后重插，验证 `loadState()` 是否正确恢复所有阈值与 `systemOn`。
7. **校准偏移后置叠加对照**：测三次同点温度，比较 nestOff 偏移前后差异，量化 DS18B20 出厂相对偏差。
